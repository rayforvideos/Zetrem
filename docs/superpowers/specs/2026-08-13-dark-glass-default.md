# 어두운 유리를 기본으로 — 덮지 않고 눌러서 어둡게 한다

2026-08-13. 사용자 요청: "배경은 건드리지 말고 그냥 창만 어두운걸 디폴트로 하되
불투명도를 낮춰서 뒤에 배경이 잘보이게" → "뒤에 배경이 잘 보이게 투명도 올리고
어둡게 만들어서 세련된 유리처럼"

## 요구가 부딪히는 지점

"더 투명하게" 와 "더 어둡게" 는 알파 하나로는 동시에 만족할 수 없다.
알파를 올리면 어두워지지만 배경이 사라지고, 내리면 배경이 살지만 판이 흐리멍덩해진다.
얇게(0.125) 내려 본 판은 실제로 "흐린 창" 이지 유리가 아니었다.

## 답: 어둡기를 알파가 아니라 backdrop-filter 가 진다

`backdrop-filter: blur(40px) saturate(1.3) brightness(0.45)`.

brightness 는 **유리가 덮은 자리의 배경만** 누른다. 사진은 그대로 있고, 판 아래를
지나는 빛만 줄어든다 — 페인트를 얹는 것이 아니라 빛을 줄이는 것이라 배경의 형태와
색이 살아 있다. 그래서 판은 어둡고 동시에 투명하다.

- 표면 알파: 사람이 색을 고르면 하한 `CHOSEN_ALPHA_FLOOR` = 0.10 (자동은 0.16).
  기본 두께 0.05 에서 실측 **0.125** — 칠은 12.5% 뿐이다.
- 표면 색: `rgb(8, 10, 14)`. 얇게 깔릴수록 어둡기는 색이 혼자 지므로 거의 검정이다.
- 블러: 32 → 40. 얇은 유리에서는 블러가 유리의 인상을 혼자 진다.
## 조작할 것이 남지 않는다

"유리 배경 자동 어둡게 이런거 필요없어" — 타이틀바의 유리 조작 뭉치(자동/어둡게/밝게
토글, 유리 두께 슬라이더, 배경 어둡기 슬라이더)를 전부 걷어냈다. 배경 dim 은 개념째
지웠다(`dimmedRange`, `BackdropState.dim`, `BackdropLayer` 의 검정 막).

노브가 필요했던 이유는 "이 사진 위에서는 읽히지 않는다" 였고, brightness 가 그 문제를
없앴으므로 노브도 함께 없어진다. 남은 상태는 배경 사진 하나뿐이고, 두께는
`GLASS_THICKNESS = 0.05` 상수다. 타이틀바에는 설정·프로젝트·배경 고르기만 남았다.

## 보증이 돌아왔다

앞선 판(2026-08-13 오전)에서는 "사람이 색을 고르면 4.5:1 을 강제하지 않는다" 는
거래를 문서에 적었다. brightness 가 그 거래를 무르게 했다: 가장 밝은 배경(휘도 1)도
0.45^2.2 ≈ 0.17 로 눌리므로, 알파 0.10 짜리 유리 위에서도 흰 글씨가 5.1:1 을 넘긴다.

`tint.test.ts` 가 모든 밝기 범위 × 두께 조합에서 `dark` 톤의 4.5:1 을 검증한다.
`light` 톤은 여전히 보증 밖이다 — brightness 로 검정을 밝힐 수는 없기 때문이다
(휘도 0.02 배경은 1.6 배를 곱해도 0.057 이라 어두운 글씨가 살지 않는다).
밝은 유리를 어두운 사진 위에 올리는 사람에게는 두께 노브와 "자동" 이 조종간이다.

## 계산 모델

CSS brightness 는 sRGB 로 인코딩된 채널값에 배율을 곱하므로, 상대 휘도는 대략
`k^2.2` 배가 된다(`SRGB_GAMMA`). `computeTint` 는 배경 범위에 이 배율을 먼저 곱한 뒤
극성·알파·스크림 계산에 들어간다 — 화면에서 실제로 유리에 닿는 밝기가 그 값이기 때문이다.
